# ball-throwing-kids：ボール投げが苦手な子ども

## 確認できた事実

### ソフトボール投げの成績低下（全国実績値）

- **事実**: 小学5年生の新体力テストのソフトボール投げは、平成20年度（2008年）の男子25.39m・女子14.85m から令和7年度（2026年）に男子21.06m・女子13.10m へと低下している。男子で4.33m、女子で1.75mの低下
- **出典**: スポーツ庁「令和7年度 全国体力・運動能力、運動習慣等調査」
- **出典URL**: https://www.mext.go.jp/sports/b_menu/toukei/kodomo/zencyo/1411922_00014.html
- **原文引用**: 小学校5年生実技テスト集計表より「ソフトボール投げ」の経年値
- **補足**: 令和7年度は直近向上傾向（令和6年度20.74m → 令和7年度21.06m）だが、ピークの平成30年度（男子22.14m）には及ばない

### 投能力低下の傾向（スポーツ庁公式見解）

- **事実**: スポーツ庁の公式コメントは「ボール投げは小中学校男子で直近向上傾向、小中学校女子で横ばい」と記載。これは短期的（過去数年）の傾向を指す
- **出典**: スポーツ庁「令和7年度 全国体力・運動能力、運動習慣等調査」概要PDF p.2～p.11
- **注記**: 長期的には平成20年度からの低下傾向は明らかだが、最近の回復傾向も公式に認識されている

### 投能力の発達段階（文部科学省ガイドライン）

- **事実**: 文部科学省の「幼児期運動指針」では、4～5歳から投げるなどの用具操作の経験が望ましいとされている。小学校の学習指導要領では低学年（1～2年）で片手投げの習得が主要な学習課題となり、中高学年で段階的に技術向上が図られる
- **出典**: 文部科学省「幼児期運動指針」「小学校学習指導要領 体育編」
- **出典URL**: https://www.mext.go.jp/a_menu/sports/undousisin/1319771.htm（幼児期運動指針）
- **原文引用**: 「4～5歳から投げるなどの用具操作の経験が望ましい」

### 投能力習得時における個人差の大きさ

- **事実**: 投げ動作の習得には個人差が大きく、同じ学年でも習得段階が異なる。これは発達の正常な範囲であり、段階的指導を通じて習得を目指す設計
- **出典**: 文部科学省「小学校学習指導要領解説 体育編」「小学校体育指導の手引」
- **注記**: 「〇歳までにこの距離を投げるべき」という発達の数値基準は、全国体力テストの値が「実績値」であって「目標値」ではない

### 指導方法（公式ガイドライン）

- **事実**: 文部科学省の指導資料では、投げ能力習得の段階として以下が示されている：
  1. 軽く小さいボールを使用する
  2. ゲーム的な学習活動による自然な習得を重視
  3. 片手投げから始める
  4. 段階的に技術を高める
- **出典**: 文部科学省「小学校体育指導の手引」
- **出典URL**: https://www.mext.go.jp/sports/b_menu/sports/mcatetop04/list/jsa_00003.htm

### 投能力低下と関連のある複数要因

- **事実**: スポーツ庁の報告書では「1週間の総運動時間が60分未満の割合は小中学校で増加傾向」と記載。またスポーツ科学の研究領域では、以下の複数要因が投能力習得に関連していると指摘されている：
  1. 幼少期の外遊び・スポーツ活動時間の減少
  2. スクリーンタイム（ゲーム・スマートフォン）の増加による活動時間減
  3. 遊び場（河原・公園など自由に投げられる空間）の減少
  4. 少子化による仲間の数の減少
  5. 幼少期の神経発達期における投げ動作経験の不足
- **出典**: スポーツ庁「令和7年度 全国体力・運動能力、運動習慣等調査」概要
- **注記**: スポーツ庁の調査は「これらが原因である」と因果を特定していない。複数の学術資料・運動指導機関が「関わっている要因」として指摘する形が正確。この複合性を記事に示すことが重要

## 未確認・記事に書けないこと

1. **投能力低下の単一原因の特定**: 「外遊び減少が原因だ」と因果を断定できない。複数要因の複合的な関連と考えるべき

2. **WHO や国際的な投げ能力の発達基準**: 国際基準がどのようなものかは確認できていない。あれば引用可能だが、単一の公式基準は存在しない可能性

3. **スクリーンタイム削減による投能力改善の実証**: 介入研究のデータが確認できていない。「スクリーンタイムを減らすと投げが上手くなる」という科学的証明はない

4. **逆上がりやソフトボール投げ以外のボール運動との関連**: 異なる種目（ドッジボール・バレーボール等）での習得と投能力の関連性は調査から明確でない

## 記事の構成案

### 「ボール投げが苦手な子ども」の現状と背景

1. **全国体力テストで見える投能力低下の事実**
   - 「平成20年度から16年間で、小5男子は約4メートル投げられなくなった」という数値で現状を示す
   - 「ただし最近は回復傾向（令和6→7年）」という複眼的記述

2. **投能力習得の発達段階**
   - 文部科学省ガイドラインの段階を記載
   - 「4～5歳から投げ経験が大切」という初期段階の重要性を示す
   - 「個人差が大きい時期」という正常な発達観を強調

3. **背景にある複数要因（因果ではなく関連性で）**
   - スポーツ庁の「運動時間減少傾向」を引用
   - 「複数の要因が指摘されている」という表現で、外遊び減少・スクリーンタイム増加・少子化・遊び場減少を列挙
   - 「これらが直接の原因と特定されているわけではなく、複合的に関わっていると考えられる」と慎重な表現

4. **習得への対策（公式ガイドライン準拠）**
   - 文部科学省の指導方法を基に「軽いボールから始める」「遊び的な活動」「段階的習得」を示す
   - 親の工夫・家庭での練習方法は、体操競技指導者資格や関連学会の提言があれば記載

5. **親への安心メッセージ**
   - 「投げが苦手なのは学習段階では珍しくない」という発達観
   - 「段階的な指導で習得することが想定されている」という学習設計

## 記事で書いてはいけないこと（絶対ルール）

1. **因果関係の断定**: 「外遊びが減ったから投能力が落ちた」と言わない。「関連がある」「複合的に関わっていると考えられる」にとどめる

2. **一次ソース未確認の研究引用**: 学術論文を引用する場合は必ず原典にあたり、スポーツ庁報告書の要約を鵜呑みにしない

3. **発達の目標値化**: 「小5男子は21m投げるべき」と実績値を目標に変えない。「全国平均は21m」という報告にとどめる

4. **単一要因の排斥的記述**: 「スクリーンタイムのせいだ」「少子化のせいだ」と一つの要因に還元しない

5. **未実証の改善方法**: 「〇〇練習法で必ず上手くなる」のような根拠なき主張。公式ガイドラインの段階的指導のみを推奨
