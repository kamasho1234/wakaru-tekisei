# game-vs-sports：ゲームばかりで運動しない子ども

## 確認できた事実

### スクリーンタイムの実態（小学5年生）

- **事実**: 平日の学習以外のスクリーンタイム（テレビ・DVD・ゲーム機・スマートフォン・パソコン等）が「3時間以上」の割合は、小学5年生男子42.5%、女子37.2%
- **出典**: スポーツ庁「令和7年度 全国体力・運動能力、運動習慣等調査」質問紙（Q8）
- **原文引用**: 調査ファイル「小学校 児童質問紙」より、スクリーンタイム「3時間以上」の集計値
- **補足**: 中学2年生の場合は、男子50.0%、女子49.3%に増加

### インターネット全体の使用実態（全年代）

- **事実**: こども家庭庁「青少年のインターネット利用環境実態調査」令和7年度版によると、小学生の61.7%が3時間以上のインターネット利用、平均233.6分
- **出典**: こども家庭庁「青少年のインターネット利用環境実態調査 令和7年度版」（2026年3月27日発表）
- **出典URL**: https://www.cfa.go.jp/policies/youth-kankyou/internet_research/results-etc/r07
- **原文引用**: 「小学生：61.7%が3時間以上、平均233.6分」

### ゲーム使用時間の実態（参考値）

- **事実**: ゲーム機に限定した使用時間は小学生の8.2%が3時間以上（平均68.6分）。スマートフォンゲームは含まれていない
- **出典**: こども家庭庁「青少年のインターネット利用環境実態調査 令和7年度版」
- **注記**: スポーツ庁調査の「スクリーンタイム」とこども家庭庁調査の「ゲーム機」は定義が異なる。前者はテレビ・DVD・ゲーム全体、後者はゲーム専用機のみ

### 運動時間と体力の関連

- **事実**: スポーツ庁公式見解として「『運動時間が長い』児童生徒ほど、体力合計点が高くなる傾向にある」「1週間の総運動時間が60分未満の割合は、小中学校男女ともに増加傾向である」
- **出典**: スポーツ庁「令和7年度 全国体力・運動能力、運動習慣等調査」概要PDF
- **原文引用**: 公式報告書 p.2～p.11 より
- **注記**: 相関関係が示されている。スクリーンタイムが高いから体力が低い、という因果関係ではなく、「運動時間が少ない傾向の子はスクリーンタイムが多い傾向にある」という連関性

## 未確認・記事に書けないこと

1. **WHO等国際機関のスクリーンタイム推奨時間**: 公式サイトのアクセス制限により確認できず
2. **スクリーンタイム長が体力低下の原因であるという因果関係**: 本調査は相関のみを示すもの。因果の断定は学術的に根拠がない
3. **ゲームの種類別（対戦ゲーム・RPG等）による運動時間への影響**: 調査では捕捉されていない
4. **スクリーンタイム削減による体力改善効果の実証**: 介入研究のデータが確認できていない

## 記事の構成案

### 「子どもがゲームばかりで運動しない」という現状

1. **スクリーンタイムの数値で現状を示す**
   - スポーツ庁調査：小5男子の42.5%が平日3時間以上のスクリーンタイム
   - こども家庭庁調査：小学生の61.7%がインターネット3時間以上利用
   - 「多くの子どもがスクリーンに接する時間が増えている」という事実を客観的に示す

2. **なぜスクリーンタイムが増えるのか（背景）**
   - テレビ・スマートフォン・ゲーム機など利用可能なデバイスの増加
   - （学術的根拠がある場合のみ記載すること）

3. **運動時間との関連性**
   - 「運動時間が長い児童ほど体力が高い傾向」を公式見解として記載
   - 「スクリーンタイムが長いから体力が低い」という因果は言わない。代わりに「運動時間が少ない子にスクリーンタイム長の傾向」と関連性を示す

4. **対策・工夫（記事に含める場合）**
   - 学術的根拠がある実例のみ。推測で「このようにすればよい」と書かない
   - 親の工夫・学校の取り組み事例は、実装者の意図が正確に引用できる場合のみ

## 記事で書いてはいけないこと（絶対ルール）

1. **因果関係の断定**: 「ゲームをするから体力が低い」と言わない。相関にとどめる
2. **一次ソース未確認の数値**: WHO等から引用する場合は必ず原典から確認。検索エンジンの要約は使わない
3. **クロス集計の詳細数値**: スポーツ庁報告書のグラフ内の数値差（例：「朝食を毎日食べる子は〇点高い」）を記事に書かない。テキスト化されていないため
4. **定性的な推測**: 「親がゲームを制限すれば…」のような推測表現。実証研究があれば別
