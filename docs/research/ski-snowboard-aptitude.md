## SAJ が統括する競技（公式サイトの競技本部より）

| 競技 | 英語表記 |
|---|---|
| アルペン | Alpine |
| クロスカントリー | Cross-Country |
| ジャンプ | Jumping |
| コンバインド | Combined |
| フリースタイル | Freestyle |
| スノーボード | Snowboard |

**記事で使える事実**: 「スキー」と一口に言っても、SAJ が統括するだけで6つの競技に分かれている。子どもがどの競技に向くかは、滑降系（アルペン）・持久系（クロスカントリー）・技系（フリースタイル、スノーボード）で性質がまったく異なる。

## スノーボード U-12FS 認定（JSBA 公式原文）

> 基本的な実技から段階を経て高度な実技までを目標とする事により達成感を得られ、その先にある公認競技会での活躍など大きな目標の第一歩となります。

| 項目 | 規定（原文） |
|---|---|
| 対象 | 小学生以下（U-12）のスノーボーダー（非会員含む）※1級はJSBA会員限定 |
| 受験料 | 各級とも1,100円（税込） |
| 公認料 | 550円（税込）※合格後にかかります |

### ジャンプ認定内容（原文の表）

| 級 | 課題 |
|---|---|
| 5級 | ストレートジャンプ（ノーグラブ） |
| 4級 | ストレートジャンプ＋グラブ |
| 3級 | 180°スピンジャンプ（ノーグラブ） |
| 2級 | 360°スピンジャンプ（ノーグラブ） |
| 1級 | 360°以下のスピンジャンプ＋グラブ |

### ジブ認定内容（原文の表）

| 級 | 課題 |
|---|---|
| 5級 | ボックスで50-50 |
| 4級 | ボックスでボードスライド |
| 3級 | ボックスで50-50からボードスライドに乗せ替え |
| 2級 | ボックスでオンかオフに180度以上のスピンを入れた50-50かボードスライド |
| 1級 | レールでボードスライドか50-50 |

> 記載内容は現段階のものですので、今後変更になる場合がございます。最新情報はJSBA公式サイトにてご確認ください。

### 認定会の実施体制（原文）

> ※認定会の開催には認定員 2名（U-12FS認定研修会で認められたJSBA公認C級以上のインストラクターかJSBA公認C級以上のジャッジ資格が有効な者）が必要です。

**記事で使える事実**: 小学生以下を対象にした公式の段階的な認定制度がある。ジャンプ系とジブ（障害物）系の2トラックに分かれており、子どもが得意な方から進められる。5級はストレートジャンプ／ボックスで50-50という、初歩から始められる設計。認定には有資格の認定員2名が必要と定められている。

## 学校体育での扱い（小学校学習指導要領解説 体育編 原文）

> (ｼ)雪遊び，氷上遊び，スキー，スケート，水辺活動などの取扱い
> 自然との関わりの深い活動については，学校や地域の実態に応じて積極的に行うことに留意することを，引き続き「指導計画の作成と内容の取扱い」に示した。

> (9)は，諸条件の整っている学校に対して，自然との関わりの深い運動の指導を奨励していることを示したものである。

**記事で使える事実**: スキーは学習指導要領で「雪遊び、氷上遊び、スキー、スケート、水辺活動」という「自然との関わりの深い活動」に位置づけられ、諸条件の整っている学校に対して指導が奨励されている。ただし全国一律の必修ではなく、学校や地域の実態に応じた扱いである点に注意して書くこと。
